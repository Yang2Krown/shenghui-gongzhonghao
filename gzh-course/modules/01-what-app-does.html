这个应用到底在干嘛？

从一个简单的操作开始：点击"挖掘选题"后，AI 帮你完成从选题到发布的全流程

一句话说清楚

想象你是一个公众号运营者。每天要做的事：找热点 → 写选题 → 写文章 → 发布。

这个平台把这四件事全部自动化了。你只需要告诉它"去挖选题"，它会自动从十几个信息源抓取最新资讯，用 AI 帮你筛选出最好的选题，生成大纲、标题、正文，最后直接推送到你的微信公众号草稿箱。

💡
为什么这很厉害？

传统写一篇公众号文章需要 3-5 小时。这个系统用 AI Agent 流水线，把时间压缩到几分钟。而且它不是简单地让 AI 写文章——它用多个 AI 角色互相审核、打分、挑刺，确保质量。

总共用了多少个 AI？

一条选题从挖掘到发布，最多经过 21 个 AI Agent。每个 Agent 专注一件事：有的负责创造，有的负责审核，有的负责挑刺，有的负责改写。这种"分工协作"是这个系统最聪明的地方。

看看 Agent 们怎么对话

这些 Agent 不是各干各的——它们像一个团队一样协作。来看看标题生成流水线里的对话：

A
Agent A · 创作者

根据大纲和角度报告，我生成了 12 个标题候选：

1. "ChatGPT 刚刚做了一件事，让所有程序员失眠"
2. "AI 写代码已经不新鲜了，但这个新能力让所有人沉默"
3. "深度解析：为什么这次 AI 更新值得你关注"

B
Agent B · 评分员

我来打分。标题 1：吸引力 9/10，信息密度 6/10。标题 3：吸引力 5/10，信息密度 9/10。

标题 2 建议否决——"让所有人沉默"太夸张了，容易被读者识别为标题党。

C
Agent C · 点击率预测

我预测点击率：标题 1 约 8.2%，标题 3 约 3.1%。标题 1 在朋友圈传播的概率更高。

D
Agent D · 最终裁判

综合评分：标题 1 = 0.6 × B评分 + 0.4 × C预测 = 7.8 分。推荐使用标题 1，但建议把"失眠"改成"重新思考"，降低标题党感。

技术栈鸟瞰

这个系统由三个主要部分组成：

🖥️

前端 · Vue 3

你看到的界面。用 Vue 3 构建，Element Plus 提供按钮、表格等组件。富文本编辑器让你可以直接编辑 AI 生成的文章。

⚙️

后端 · FastAPI

处理所有逻辑的大脑。用 Python 的 FastAPI 框架，管理 25+ 个 API 接口。所有 AI 流水线、爬虫、数据库操作都在这里。

🗄️

数据层

PostgreSQL 存储所有数据，pgvector 做语义相似度搜索，Redis 配合 Celery 处理后台任务（爬虫、AI 流水线）。
