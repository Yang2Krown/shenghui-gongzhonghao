# 小红书本地采集节点

本程序在 Mac 本地运行 `xiaohongshu-cli`，Cookie 不上传服务器。服务器只接收标准化素材、运行进度和风险状态。

## 安装

1. 在后台“小红书采集监测”生成 10 分钟有效的绑定码。
2. 双击 `install.command`，输入绑定码。
3. 安装完成后由 macOS `launchd` 自动常驻和定时运行。

默认安全规则：每天执行全部启用的基础词，并从当天可执行的总结词中稳定随机抽取最多 5 个（不足 5 个则全部执行），统一分散到 09:30–22:30，每次只执行一个。关键词数量由服务器端关键词管理实时决定；约 35 个词时相邻时间槽约 20–25 分钟。每个时间点只有 12 分钟执行窗口，Mac 离线、暂停或繁忙而错过时直接跳过，不在稍后集中补跑。全局单并发、详情间隔 20–40 秒；遇到验证码、461 或 471 立即暂停当天计划，等待在监测页人工验证，验证成功后由管理员手动继续。今日时间轴、下一关键词和完成状态会同步到后台监测页，Cookie 始终只保存在本机。
