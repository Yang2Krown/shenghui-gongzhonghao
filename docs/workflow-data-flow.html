💡 关键机制

所有中间数据都通过父组件 CreationEditor.vue 的 ref 变量中转，不直接在子组件间传递。

每个子组件通过 emit('complete', data) 把结果交给父组件，父组件存到 ref 里再通过 props 传给下一个子组件：

  • currentOutlineData — 大纲数据（大纲→标题、大纲→正文都用这个）
  • selectedTitle — 选中的标题（标题→正文）
  • finalContent — 最终正文（正文→保存草稿）

后端方面，大纲生成是唯一直接消费 angle_report 的步骤；标题生成和正文生成都是通过 candidate_id + outline_id 从数据库读取前面步骤产生的数据。
